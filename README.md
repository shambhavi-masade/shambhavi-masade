# Simple React Application (State and Props)

This project is a basic ReactJS web app that demonstrates:
- **State** with `useState`
- **Props** to pass dynamic data between components

## Features
- A reusable `ProfileCard` component that receives data through props.
- A reusable `CounterCard` component that receives value + event handlers via props.
- Interactive buttons that update state and trigger real-time UI rendering.

## Run locally
Because this app uses React from CDN, you can run it with any static server:

```bash
python3 -m http.server 4173
```

Then open:

```text
http://localhost:4173
```
